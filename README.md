# CSV データ確認アプリ

CSVファイルをアップロードし、データの確認ができる Streamlit アプリです。  
列名、データ型、欠損値、数値の集計結果、グラフ表示などをブラウザ上で簡単に確認できるようにしました。

## 概要

Python（pandas、NumPy、Streamlit）を用いて、CSVデータの確認を行うアプリを作成しました。  
列名、データ型、欠損値、集計結果を確認できる機能に加え、折れ線グラフ、棒グラフ、ヒストグラム、散布図による表示機能も実装しました。

また、用途ごとに画面を分けることで、データの確認とグラフの表示を分けて使えるようにしました。  
`session_state` を活用し、ページ遷移後もデータを保持できるよう設計するなど、操作性も意識して開発しました。

## 作成目的

CSVデータの確認やグラフ表示を行うアプリを作る中で、pandas によるデータ処理と Streamlit による画面作成を実践的に学ぶことを目的としました。

## 主な機能

### 1. CSVアップロード
トップページで CSV ファイルをアップロードし、アプリ内でデータを保持します。

### 2. データ確認
データの中身を表形式で確認できます。  
あわせて、列名・データ型・欠損数・欠損率なども確認できます。

### 3. 数値データの集計結果の表示
数値列に対して、件数・平均・標準偏差・最小値・中央値・最大値などを確認できます。

### 4. CSVダウンロード
フィルタ後の表示結果を CSV 形式でダウンロードできます。

### 5. グラフ表示
選択した数値列をもとに、以下のグラフを表示できます。

- 折れ線グラフ
- 棒グラフ
- ヒストグラム
- 散布図
